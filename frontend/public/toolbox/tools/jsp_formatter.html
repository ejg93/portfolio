JSP/HTML 줄정리

들여쓰기 짧은 태그 한 줄 유지 한 줄 최대 연속 빈 줄 1개로 스크립틀릿 { } 반영
입력 (JSP / HTML 붙여넣기 · 파일을 끌어다 놓아도 된다 — 여러 개면 일괄 정리) 파일 인코딩
결과 비교
※ 붙여넣은 JSP·HTML 의 태그 사이 공백만 줄바꿈·들여쓰기로 재배치한다.
태그·속성·텍스트 내용은 건드리지 않는다. <pre>·<textarea> 내부는 공백까지 바이트 그대로 둔다.
<script>·<style>·주석·스크립틀릿 내부는 상대 들여쓰기를 유지한 채 블록 위치만 옮긴다.
구조상 못 고치는 한계:
① 인라인 요소 판정을 HTML 기본값 목록으로 한다. CSS 로 display 를 바꾼 요소는 소스만 봐서 알 수 없어, 그 요소 사이 공백 재배치가 화면 간격을 바꿀 수 있다 → 정리 후 육안 확인.
② 스크립틀릿 분기로 태그를 반쪽씩 여닫는 레거시는 실행 전까지 태그 짝이 정해지지 않는다 → 들여쓰기 깊이가 틀어질 수 있다. 내용 자체는 보존된다.
비교 탭: 정리 전후를 토큰 단위로 맞춰, 태그가 사라지거나 순서가 바뀐 곳 · 인라인 요소 사이 공백이 새로 생기거나 없어진 곳 · <pre>·<textarea> 내부 들여쓰기가 옮겨진 곳을 행번호와 함께 뽑는다.
들여쓰기만 바뀐 줄은 표시하지 않는다.
