# 청약 공고문 조건 코드화 실측 (2026-10-25)

청약 판정 규칙이 실제 입주자모집공고문 조건으로 버티는지 잰 결과다.
판정 항목마다 API 필드(A)·법령 고정값(B)·공고문 정형 문구 자동 추출(C1)·「확인 필요」(C2) 중 어디서 판정되는지 숫자로 갈랐다.

## 1. 무엇을 쟀나

- 모집단: 청약홈 분양정보 API, 수도권(서울·경기·인천) 공고일 2025-10-25~2026-10-25. APT 194건 + 무순위 245건 = 439건. 판정 대상(APT 민영·국민, 무순위 `HOUSE_SECD=04`)은 389건
- 공고문 PDF: 439건 중 405건(92.3%) 텍스트 추출. 실패 34건 중 32건은 APT 상세 페이지에 첨부 링크가 없다
- 정독 표본 30건(APT 민영 10·국민 5·무순위 15, 지역 고루, 공고일 등간격). 정규식은 조정용 10건만 보고 고쳤고 정확도는 평가용 20건으로 쟀다
- 판정 대조: 가상 신청자 3명(서울 장기 무주택·경기 단기 거주 청년·서울 1주택) × 공고별 대표 주택형 = 90행. 엔진은 승인된 화면 시안의 판정 함수를 그대로 옮긴 것이다

## 3. 오판

90행 중 엔진과 정답이 같은 행 82, 오판 6, 정답 판단 보류 2.

| 공고 | 신청자 | 엔진 | 정답 | 원인 |
|---|---|---|---|---|
| `REMNDR_2026910025` | 서울 거주 | 신청 가능 | 불가 | 경기도 거주자만 신청 |
| `REMNDR_2026910050` | 경기 거주 | 신청 가능 | 불가 | 서울 거주자만 신청 |
| `REMNDR_2026910094` | 서울 거주 | 신청 가능 | 불가 | 경기도 거주자만 신청 |
| `REMNDR_2026910123` | 경기 거주 | 신청 가능 | 불가 | 서울 거주자만 신청 |
| `REMNDR_2026910182` | 서울 거주 | 신청 가능 | 불가 | 경기도 거주자만 신청 |
| `REMNDR_2026910270` | 경기 거주 | 신청 가능 | 불가 | 서울 거주자만 신청 |

6건 모두 무순위 거주지 요건이다. 엔진은 이 요건을 「확인 필요」로만 띄우고 상태를 바꾸지 않는다. 무순위 표본 15건 중 7건이 자격을 특정 시도(6건)나 수도권(1건) 거주자로 묶었다.

판단 보류 2건(`APT_2026000041`)은 국민주택 일반공급의 소득·자산 기준 때문이다. 가상 신청자에 소득 정보가 없다. 국민주택 표본 5건 모두 정답 기록에 소득 기준이 나오고, 그중 `APT_2026000041`·`APT_2026000373` 은 일반공급 요건으로 명시한다. 엔진에는 이 항목이 없다.

1순위 접수 구분(해당지역·경기·기타지역)은 경기 거주 신청자 행 15개 중 8개가 어긋났다.
- 인천 공고 3건: 엔진이 「경기」로 냈다. 시안이 경기 접수일 칸이 비어 있어도 그 칸을 고른다
- 시 단위 해당지역 경기 공고 3건(부천·양주·남양주): 엔진이 「해당지역」으로 냈다. 실제 해당지역은 그 시 거주자뿐이다
- 경기 거주자를 따로 받는 경기 공고 2건(파주·평택): 엔진은 「해당지역」, 정답은 「경기」

## 4. 「확인 필요」 비율

엔진 90행 전부에 「확인 필요」가 하나 이상 붙었다. 특별공급 안내·무순위 거주지 안내가 거의 모든 공고에 뜨기 때문이다. 이대로면 「확인 필요」 뱃지가 아무것도 가르지 못한다.

## 5. API 필드

- 판정에 쓰는 필드(공고일·1순위 접수일·투기·조정·공공주택지구·주택형 전용면적·분양가·공급 세대)는 판정 대상 389건에서 결측·형식 오류 0
- `GNRL_RNK1_ETC_GG_RCPTDE`(경기 거주자 1순위 접수일)는 경기 공고 116건 중 35건에만 있고 서울·인천 공고에는 없다
- 무순위 상세에는 `SPECLT_RDN_EARTH_AT`·`MDAT_TRGET_AREA_SECD`·`PUBLIC_HOUSE_EARTH_AT`·`HOUSE_DTL_SECD` 가 아예 없다(0/213)
- 공고문의 규제 표기가 API 와 다를 수 있다. `REMNDR_2025910205` 는 지역이 투기과열지구로 지정됐지만 공고문이 「비규제지역 기준으로 공급」 한다고 적는다
